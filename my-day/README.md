# My Day

A personal dashboard you can install on your phone's home screen. It has a focus list, countdown, weekly habits, scratchpad and quick links. Data stays on the device (localStorage) and the app works offline.

## Run locally
    cd my-day && python3 -m http.server 8000   # open http://localhost:8000

## Install on a phone
Host the `my-day/` folder over HTTPS (for example GitHub Pages), open the URL on the phone, then:
- iPhone: Safari > Share > Add to Home Screen
- Android: Chrome > menu > Install app
